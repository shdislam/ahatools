About this tool

Weak passwords are behind most account takeovers. This generator uses your browser's cryptographic random number generator (Web Crypto API) — the same standard used by security software — and creates passwords that never leave your device because there's no server to send them to.

How to make a strong password here

  1. Keep length at 16+ characters — length beats complexity every time.
  2. Leave all character sets checked for maximum strength.
  3. Generate → Copy → paste into the site's password field. Save it in a password manager.

FAQ

Is this password stored anywhere?

No. It exists only in your browser tab's memory until you close it. There's no logging, no server, no database — verify by going offline: it still works identically.

Can hackers guess crypto-random passwords?

Not practically. A 16-character random password has ~10²⁵ combinations; at a trillion guesses per second that's over 80 million years of average search time.
